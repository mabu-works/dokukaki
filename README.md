# ドクカキ｜ドキュメント書き込みツール

PDFや画像（PNG/JPG）を開いて、その場で手書きやテキストで書き込める静的Webサイトです。ビルド不要で、ブラウザだけで動作します。

**ファイルはブラウザの外に送信されません。** 開いたファイルや書き込み内容がサーバーや外部サービスへ送られることはありません。すべての処理はお使いの端末のブラウザ内で完結します。

## 機能

- PDFと画像（PNG/JPG）をファイル選択とドラッグ＆ドロップで読み込み、ページを Canvas に表示
- PDF描画は同梱の pdf.js（`lib/`、バージョン 3.11.174）を使用し、外部 CDN には依存しません
- ページごとに独立した書き込みレイヤー（ベース画像 Canvas の上に注釈 Canvas を重ねる方式）
- ツール：ペン（フリーハンド）／マーカー（半透明の太線）／テキスト（入力してクリックで配置）／消しゴム（`destination-out`）
- 色選択・線の太さの調整、元に戻す／やり直し（ページごとに履歴を保持、最大50件）
- ページ送り（前へ／次へ、ページ番号表示）とページ一覧（サムネイル）からの移動
- スライドショー：フルスクリーン表示で書き込みごとページをめくるプレゼンモード（矢印キー・クリックで送り、Esc で終了）
- 書き込みデータを localStorage に自動保存（ファイル名＋サイズ＋最終更新日時で識別し、同じファイルを開き直すと復元）。「保存した書き込みを消す」ボタンで削除可能
- PNG書き出し：現在のページ（書き込み合成済み）／全ページ
- PWA対応（ホーム画面に追加可能、オフラインキャッシュ。pdf.js もキャッシュ対象）
- ダークモード対応（prefers-color-scheme）

## 使い方

1. 「ファイルを選択」するか、PDF／PNG／JPGをドラッグ＆ドロップして開きます。
2. ツール（ペン／マーカー／テキスト／消しゴム）と色・太さを選び、ページ上に書き込みます。
3. ページ送りボタンやページ一覧のサムネイルでページを移動します（書き込みはページごとに保持されます）。
4. 書き込みは自動でブラウザに保存されます。同じファイルを開き直すと復元されます。消したい場合は「保存した書き込みを消す」を押してください。
5. プレゼンは「スライドショー」から。矢印キーやクリックでページを送り、Escで終了します。
6. 保存したい画像は「現在のページを PNG で書き出し」または「全ページを PNG で書き出し」でダウンロードできます。

## 技術メモ

- 素の HTML / CSS / JavaScript ＋ 同梱の pdf.js のみ。フォントはシステムの日本語フォントスタック。
- pdf.js は cdnjs の 3.11.174 を `lib/pdf.min.js` / `lib/pdf.worker.min.js` として同梱し、`workerSrc` にはローカルパスを指定しています。実行時に外部 CDN へはアクセスしません。
- 各ページはベース Canvas（PDF／画像の描画）と注釈 Canvas（書き込み）を別々に保持し、表示時は重ねて、書き出し時は合成して PNG 化します。
- 自動保存のキーは `kakiko:<ファイル名>:<サイズ>:<最終更新日時>` です。保存先は同一ブラウザの localStorage のみで、外部には送信されません。
- Service Worker（sw.js）が同一オリジンの GET をキャッシュします（キャッシュ名: kakiko-v1、pdf.js を含む）。
